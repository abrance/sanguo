一回合 = 一个月 · 你是乱世中的一城之主

你效忠的势力统一全图为胜；你的直辖城全部失守则流亡投奔（尚有生机），无处可投为败。
点「结束回合」结算一月。结算顺序固定：行军抵达 / 营造推进 / 经济产出 / 士族情绪 / 科研 / 太守委任 / 持续调兵 / 上意与上命 / 晋升 / AI 行动。 春夏秋冬各有系数：秋粮税最厚、征兵建设最佳，冬最贫、士气下滑，春粮少但征兵快。
资源每月进账花在哪 / 代价
粮草 农田等级 × 78 × 季节 × 人口 × 治安 × 士族 × 科技；上级赏赐；借粮（600 钱） 兵力口粮 + 人口口粮（每月自动扣）。断粮：治安 −5，按缺口逃兵 4%~16%（粮仓可减轻）。上限 = 800 + 农田×400 + 粮仓×250（科技/天赋更高）
钱币 市集等级 × 30 × 季节税 × 人口 × 治安 × 士族 × 科技 × 关市（每级 +10%）；上级赏赐（忠臣路线 / 好感 >80） 营造、征兵、外交（遣使 300 / 密约 800 / 求援 1000 / 借粮 600 / 行贿 500）、求援援军。只有直辖城的钱归你支配
建材 (28 + 伐木场×13 + 采石场×21) × 季节；上限 = 400 + 伐木×500 + 采石×800 营造（越高级越贵）。不足时先补伐木/采石，否则什么也造不了
铁料 (4 + 冶铁坊×7) × 科技；上限 = 200 + 冶铁坊×400 营造高级建筑。冶铁坊每级还使器械兵额 +10%
科研点 学宫每级 6 点/月（守将政治属性加成），无学宫只能蹭 1.5 点 研习 40 项科技（农 / 工 / 商 / 军）。科研点是势力共享的，不止你直辖城在产
战功 攻下一城 +25；完成上命 +18~40 升官阶（县长 → 丞相 7 级）：提高直辖城上限、解锁外交权限与权柄。
扣：抗命 −12、上命逾期 −8、失城流亡 −10；带城投靠会清零
声望 攻下一城 +8；完成上命 +8；每次晋升 +15；每月 round(Σ(治安−45)/100)，只算直辖城 目前只有一个用途：举兵自立需 150（另需刺史官阶 + 2 座直辖城）。
扣：背刺 −15、行贿被同僚检举（15%）−5、失城流亡 −10
上意
（君主好感）		 忠臣路线 +0.8/月；权臣路线 −1.2/月，另每月 20% 遭猜忌 −6~12；行贿 +12 好感 >80：每月获粮钱赏赐、直辖上限 +1；<30：直辖上限 −1；<25：每月 10% 概率被削一城。
扣：遣使 −2、借粮 −3、求援 −5、密约败露 −15、背刺 −20、抗命 −25、上命逾期 −15
天赋加成只作用于你的直辖城与军队：商人 钱 +25% / 外交 −25%，农夫 粮 +25% / 仓廪 +30%，工匠 建材铁料 +20% / 工期 −25%。
点地图上的城 → 侧栏分 概览 / 营造 / 士族 / 施政。
直辖城多时，城池页顶部有直辖城切换条（点名字即切城，不用回地图）与一键理政条（方针 / 补兵 / 安抚全体一次做完）。
嫌逐城管太累可开军区：委一名都督统辖多城，每月自动营建、征兵、出兵；号令决定它守土 / 拓边 / 征讨某一家。
营造：16 种建筑，等级越高越贵，各有上限。
士族：情绪影响产出与兵额，过低会叛乱，需安抚或打压。
施政：设定太守方针（重农 / 备战 / 商贸 / 筑城 / 均衡），太守按方针自动营造与征兵。
只有直辖城能建设出兵；势力其他城由 AI 守备，只读。可直辖数受官阶限制，攻下的城满了则归势力、你只拿战功。
五兵种：步 / 弓 / 骑 / 水 / 器。克制 骑 > 步 > 弓 > 骑（±30%），器械削城墙加成。
攻城为多轮结算（最多 6 轮）：守军掉到一成则城破，攻方掉到三成则退兵。城墙每级约 +22% 守方战力。
出兵前把鼠标悬到目标城可看胜算预估（可克 / 难克 + 余兵估计）。
「军务」页可批量操兵：选城 → 选抽取比例 → 补齐所选 / 调兵，再点地图目标城。
城池面板可设持续调兵，每月自动输送，用于长期压制或补给前线。
四种状态：交战 可攻；中立 攻之即背刺（威望与人望双失）；停战 期内不可攻；同盟 互不攻，盟友受攻可能来援。
三档权限随官阶解锁：个人外交（遣使 / 密约 / 求援 / 借粮 / 行贿）、上表言事（请君主宣战 / 求和 / 结盟 / 离间）、代君行令（三公或自立之主）。
战功 升官阶（县长 → 丞相，共 7 级，直辖城上限随之提高）；声望 影响自立与他人态度；上意（君主好感）影响赏赐与削权。
君主会派上命，限期内完成得战功，逾期或抗命掉上意。
三条路线：忠臣（稳、上意高）、权臣（内政军务加成、招猜忌）、自立（需官阶 + 城数 + 声望达标），点「官阶台」查看与切换。
