# 美术与手感第二批：城池 / 底图 / 破城反馈

> 状态：**规格，未实现**。三个目标各一节，每节都是「现状（带代码位置）→ 目标 → 手法 → 代价 → 验收」。
> 相关：[VISUAL.md](VISUAL.md) §2 城池方向 · §12 行军路线 · [STYLE.md](STYLE.md) 分层与 token 红线。

## 0. 预算基线（先看这个，它决定了后面所有做法的顺序）

本机实测（软件光栅化，`window.rasterProbe()`，1327×979 画布、70 城）：

| 机位 | 单帧光栅化 | 说明 |
|---|---|---|
| zoom 0.5（远景，城池画成色点） | **1.9ms** | 底图 `drawImage` + 军队 + HUD |
| zoom 1.0（近景，城池画立面） | **8.3ms** | 城池立面约吃掉 6ms |
| zoom 2.2（最大放大） | **6.9ms** | 屏内城池变少，摊平 |

`docs/VISUAL.md` §11.6 自定的预算就是「`Renderer.draw` < 8ms」——**已经吃满了**。
结论先写在前面：

> **所有新增的城池细节一律烘焙进 per-city 缓存位图，不进每帧路径绘制；底图细节全部进 `prerender()` 的一次性烘烤；破城反馈只在 1.5s 特效窗口内花钱。**

违反这条，任何「更精致」都会先把帧率打下来，玩家感受到的是卡，不是美。

## 1. 城池：从「色块」到「建筑」

### 1.1 现状（`js/view/renderer.js` `drawCity`，约 200 行）

| # | 现状 | 观感后果 |
|---|---|---|
| 1 | 城体颜色 = 势力色，`shade(color, 0.62/0.75)` 只是等比压暗 | 满屏大色块；城看起来像势力色马克笔涂的方块，不像**建筑** |
| 2 | 立面只有南/东两个纯色平行四边形 | 只有「明暗」没有「冷暖」，立体感薄 |
| 3 | 屋顶全是 `fillRect` 水平矩形（门楼、角楼、内城） | 天际线是平的直尺线，没有坡屋顶的「脊」 |
| 4 | 院内只有一圈压暗底 `rgba(12,10,8,0.34)` | 院子是空的 —— 放大看是「一块空地套个框」 |
| 5 | 等级差异只有：尺寸 / 雉堞数 / 角楼数 / tier2 才有内城 | 县城与郡城一眼看过去差不多 |
| 6 | 阴影 = 1 个软椭圆 + 1 条 0.8px 硬线 | 接地感有，但没有 AO，墙根发飘 |
| 7 | 砖纹 / 瓦垄 / 窗洞：**0 处** | 近景没有可看的细节，只有色块边界 |

### 1.2 目标

近景（zoom ≥ 1.2）下，不看旗也能从**建筑语言**判断：这是县城（一圈土墙）、郡城（门楼 + 角楼 + 内院小屋）、都城（双城 + 马面 + 重檐主楼）；势力归属靠**旗 + 檐边 + 门匾 + 城下光晕**读出来，而不是靠墙色。

### 1.3 手法（按性价比排序，1 最高）

**① 材质与势力色分离**（改动集中在 `drawCity` 的取色，收益最大）

```js
// 新增 palette，城墙/屋顶用中性材质色；势力色降级为点缀
CITY = {
  rammed: { base:'#6b6152', light:'#7d7260', dark:'#4a4238' },  // 夯土墙（县城）
  stone:  { base:'#6e6a60', light:'#847f72', dark:'#4b4740' },  // 砖石墙（郡城/都城）
  tileBlue:{ base:'#3d4550', light:'#4c5663', dark:'#2a303a' },  // 青瓦（主楼/门楼）
  tileRed: { base:'#5a3630', light:'#6d453c', dark:'#3a221e' },  // 朱瓦（都城/帝都）
}
```
势力色只剩 4 处：旗、檐口描边（1px）、门匾、城下地环光晕。**这一条改完，地图整体气质就变了**——色块消失，城市浮出来。

**② 双坡屋顶 + 檐口线**：门楼 / 角楼 / 内城主楼由 `fillRect` 改为「矩形墙身 + 平行四边形坡顶」：
受光面 `light`、背光面 `dark`，檐口画 1px `rgba(0,0,0,.45)`；屋脊一条 1px 亮线。仅此一步，天际线从「直尺」变成「屋顶」。

**③ 三面收光 + 冷暖分离**：把 `shade()`（纯乘法）换成 `shadeTint(hex, k, warm)`：

| 面 | 系数 | 色温偏移 |
|---|---|---|
| 顶面 | 1.00 | 0 |
| 东面（受光，西北光） | 1.08 | R +4 |
| 南面（背光） | 0.62 | B +5（偏冷） |
| 墙根 1/3 | 再 ×0.86 | 模拟 AO |

**④ 城基接触阴影 + 院内 AO**：地影保持椭圆，另加一条 3px 半透软边（alpha .18）；院内四角各一次小 `radialGradient`（tier2 才画），让院子有「墙角变暗」的纵深。

**⑤ 等级阶梯**（把 §11.1 的分档真正落到几何上）

| tier | 轮廓 | 新增件 | 城墙等级驱动 |
|---|---|---|---|
| 0 县城 | 单圈方城 | 1 门、无角楼 | 墙厚、雉堞密度 |
| 1 郡城 | 方城 + 内院 | 门楼、2 角楼、院内 2–4 间小屋 | + 砖纹 1–3 行 |
| 2 都城 | 双城（外郭 + 内城） | 4 角楼、马面、主楼重檐、院内 4–6 间小屋 | + 瓦垄、砖纹 3 行 |

**⑥ 城内填充**：按 `cityId` 播种（`U.hash(c.id)`）放 3–6 间 2–4px 小屋，每间「墙身 + 一条斜屋顶线」，只用两个色阶。院子不再空白。

### 1.4 代价与工程约束（关键）

每城当前约 30–60 次路径调用，上面 ①–⑥ 会把它推到 ~90–120 次；70 城里屏内常有 8–15 座 → **单帧会从 8.3ms 冲到 15ms+**。

**必须烘焙**：新增一个 `Renderer.citySprite(tier, wallLv, damaged, imperial)` 缓存（`Map` / 定长数组），离屏 canvas 尺寸 = `cityFoot` × (1 + ISO.height) 再留 4px 边；缓存键只含几何与材质，**不含势力色与状态光效**（旗 / 光晕 / 选中环 / 光效仍在主画布画）。最多 3×5×2×2 = 60 张，实际命中率极高。

- 每帧城池只剩：1 次 `drawImage` + 旗 + 环 + 光点 ≈ 6 次调用 → 预计 **3ms 以内**（比现在还快）
- 代价：损坏态 / 城墙等级变化时要重烘焙（一局里次数很少，且只在 `state` 变更时）
- `shots.js` 会报大量差异，属于预期；验收看「既有元素不允许位移」这一条

### 1.5 验收

1. `rasterProbe()`：zoom 1.0 ≤ **5ms**（烘焙必须让它比现在更快）
2. 全图截图（zoom 0.5 / 1.0 / 2.0 三档）能不看旗区分三档城、能看出城墙等级、能看出被打过
3. 势力色在地图上占比显著下降，但仍能 3 秒内读出归属（旗 + 光晕 + 檐边）
4. `shots.js` 8 机位人工过一遍；差异只允许「城体细节变化」，不允许城池位置/尺寸漂移

## 2. 底图：从「40px 台阶」到「老地图」

### 2.1 现状（`js/view/map.js` `prerender`，约 200 行）

| # | 现状 | 观感后果 |
|---|---|---|
| 1 | 色床按 `grid[gy][gx]` **硬分类**上色，0.4 倍分辨率双线性放大 | 地形边界是 40px 网格的台阶（VISUAL.md 已知弱点 1 未解决） |
| 2 | 山形每格至多 1 座，`n1 > 0.5` 砍一半；树每格 3 棵 | 密度均匀 = 贴纸平铺，看不出「山脉」与「森林」 |
| 3 | 山/树只有一种形态、一种尺寸 | 无层次，远景近景一样大 |
| 4 | 无等高线、无山脚投影、无地面纹理方向 | 山地与平原只靠色相区分，缺「地形语言」 |
| 5 | 河川 4 叠但**等宽**（15px / 6px 固定） | 河像一根绳子，没有源窄尾宽 |
| 6 | 纸纹 = 5200 随机会 + 420 根纤维；暗角纯黑 | 少了「旧纸」的层次与暖度 |

### 2.2 手法

**① 软权重混合（消掉 40px 台阶）**：低分辨率循环里已经有 `HF`（高度场）。把「查一格 key」换成「双线性取 4 邻格地形，按 `HF` 抖动阈值 `mix()`」：

```js
// 伪代码：两地形按噪声权重混合，权重边界用 hash 抖动 ±0.08 打碎成手绘感
const t0 = terrainOf(gx, gy), t1 = terrainOf(gx+1, gy);
const w = smooth(HF[i] * 1.15 + (hash(x,y)-0.5)*0.16);
let col = mix(PALETTE[t0], PALETTE[t1], w);
```
成本：色床内循环每像素多 2 次 `mix`（已在全图一遍，预渲染期，不影响帧）。

**② 等高线（老地图的灵魂）**：用 `HF` 出 8–12 条等值线，只在 `mountain/hill` 区域、`lineWidth 0.7`、`rgba(58,46,32,0.26)`，取样点带 `_hash` 抖动。一次预渲染，零帧成本，是**单项观感提升最大**的一步。

**③ 山形 / 树丛：聚簇 + 三档 + 双形态**

| 要素 | 做法 |
|---|---|
| 聚簇 | 用一层低频 fbm `cluster(x,y)`（波长 ≈ 400px）当密度遮罩：`density = 0.25 + cluster*0.9`，替换现在均匀的 `n1 > 0.5` |
| 山 | 3 档尺寸（8 / 14 / 22px）+ 2 种形态（单峰 / 连峰三尖）；主峰画「背光半坡」填充，山脚加 1 个横向 6×2px 投影椭圆 |
| 树 | 2 种形态（圆冠 / 尖冠）+ 3 档尺寸；同簇内尺寸随机但中心偏大 |
| 沙漠 | 沙丘弧线改成 2–3 道平行弧 + 端部点阵（现在只有 1 道） |

**④ 水系**：河宽沿弧长渐变（源 5px → 下游 16px，`pass()` 拆成 6 段分别 stroke）；岸线加 1px 抖动与滩涂点阵；河口/湖泊加 2–3 个「沙洲」椭圆 + 一条高光斜线。

**⑤ 纸的层次**：三层叠加 —— 大尺度淡渍（2 处，用两张不同波长的 `_fbm` 阈值出「水渍边」）+ 纤维 420 根（已有）+ 细颗粒 5200 点（已有）；暗角从 `rgba(0,0,0,.58)` 改成 `rgba(58,44,28,.46)` 的暖褐，避免四角死黑。

**⑥ 可选动效（默认关）**：`Renderer.OPTS.waterShimmer`，只在 `zoom ≥ 1.4` 时给水面加一条随时间平移的高光带（每帧 1 条 `quadraticCurveTo`）。默认关，因为「静止不重绘」是现在的省电根基。

### 2.3 代价

- 全在预渲染：`prerender()` 一次性耗时从 ~0.4s 涨到 ~0.8s（可接受，开局一次）
- 配色会整体变化 → `map-far/map-near` 两机位必然大改，需人工过一眼
- 等高线与州界虚线（4.6px 绢底 + 2.4px 墨线）可能打架 → 等高线 alpha ≤ 0.26、线宽 ≤ 0.7

### 2.4 验收

1. 全图截图：放大到 3 倍检查地形边界 —— **不允许再看到 40px 直角台阶**
2. 一眼能指出山脉走向与森林片区（不是均匀颗粒）
3. 等高线在 mountain/hill 内连续，不与州界混淆
4. `prerender()` ≤ 1.2s；帧内零新增开销（`rasterProbe()` 远景仍是 ~1.9ms）

## 3. 破城正反馈：音效 + 展示（0 → 2.0s 编排）

### 3.1 现状

| 层 | 现状 | 缺口 |
|---|---|---|
| 音效 | `Audio.play('siege')` = triangle 120→60Hz 0.4s + 噪声 400Hz 0.4s（`js/view/audio.js`） | 单层撞击，没有「瓦砾」「号角」「胜负区分」；无总线、无混音、无包络形状 |
| 视觉 | `Renderer.drawFx`：0.7s 扩环 + 火光 + 白闪（`renderer.js` `addFx/drawFx`） | 只有「一圈光」，没有粒子、没有镜头反馈、没有翻旗 |
| 信息 | 纪事一行 + `.bcard` 卡片 + toast | 没有「战功 +25」冒字、没有数字滚动、没有晋升仪式 |
| 手感 | 无 | 破城是全局最该爽的一刻，现在是「环扩一下，日志加一行」 |

### 3.2 目标

破城瞬间 400ms 内叠三层冲击（**震 / 光 / 声**），1.2s 内把「得到什么」讲清楚（冒字 + 滚动 + 计数）；胜负**闭眼能分辨**；连破有递进感；全程不卡、不晕、可关。

### 3.3 时间轴（一次城破的总谱）

| t | 层 | 具体做法 | 代码位置 |
|---|---|---|---|
| 0ms | 视觉 | 命中白闪 `rgba(255,240,200,.16)` 2 帧（已有雏形，加一层整屏 16ms） | `drawFx` |
| 0ms | 镜头 | 震动：`Renderer.shake = {amp:3, ms:220}`，每帧 offset = `amp*(1-t)²` 沿 hash 方向，**只作用于最终 draw 的 translate，不污染 cam / 命中坐标** | 新增 `Renderer.shakeFx()` |
| 0ms | 音频 | 冲击：sine 95→42Hz，0.35s，attack 4ms、decay 指数；+ 噪声 burst 低通 320Hz 0.12s | `Audio` 新事件表 |
| 80ms | 音频 | 瓦砾扬尘：带通噪声 900→300Hz，0.9s，attack 5ms → 长衰减 | 同上 |
| 100ms | 视觉 | 城门碎块 12 粒：2–3px 方块，初速 `40–110px/s` 沿法线扇开，重力 480px/s²、摩擦 0.92、寿命 0.6–0.9s，落地后留 0.2s 静止 | `Renderer.fx` 扩展 particles |
| 250ms | 视觉 | **翻旗**：敌色旗 `scaleY 1→0`（120ms）→ 换我方色 → `0→1`（160ms）；旗帜语义变化本身就是最强的正反馈 | `drawFlag` 加 `flip` |
| 350ms | 音频 | 胜利号角 3 音（A4-C5-E5，短-短-长，三角波 + 低通 2.4kHz + 短混响）；**只在玩家破城时** | 音频事件表 |
| 400ms | 信息 | 战报卡从右侧滑入（`--t-med`，复用现成过渡）；`+25 战功` 冒字上浮 24px 淡出 1.2s；战功/声望数字 `count-up` 300ms | `ui.js` `flash` / `renderLog` |
| 600ms | 信息 | 若跨晋升阈值：战功条金色扫光（300ms）+ 落章（复用 `.end-seal` 的 `sealStamp` 动效） | `rank.js` |
| 失败 | 全部换向 | 同一套骨架，但：音换成下行小二度 + 更闷的低通（320Hz）；无号角、无冒金；文字用 `--war` 暗红；震动 2px/160ms | 同上，按 `captured` 分支 |

**连破递进**：同一回合第 n 次破城（n ≤ 4），号角基频 +2 半音（`2^(2n/12)`），战报右上角累加「本回合破 N 城」；n > 4 不再升调（防刺耳）。

**混音**：破城期间 `sfx` 总线 duck 到 0.35（0.3s hold），避免与翻月/出征叠成一团；总线挂 `DynamicsCompressor`（threshold −18dB，ratio 6）防爆音。

### 3.4 音频工程化（现在只有 5 个 `_blip` 单音）

| 现状 | 改成 |
|---|---|
| `play(name)` 里一个大 `switch`，每音现建 `OscillatorNode + GainNode` | 事件表 `SFX = { capture: [ {t:0, layer:{...}}, {t:0.08, ...} ] }`，`play()` 只负责排程 |
| 只有 `exponentialRampToValueAtTime` | `env()` 支持 attack/hold/decay 三段包络（冲击音靠 attack 才「硬」） |
| 无总线 | `master` / `sfx` / `ui` 三路 GainNode + 压缩器 |
| 无空间 | 一次性生成 0.6s 噪声 IR → `ConvolverNode`，给号角与破城用（CPU 低，只在播放时） |
| 无优先级 | 同帧同类去重（已有 250ms 节流，保留）+ 破城级音效抢占（打断当前 sfx） |

### 3.5 代价与风险

- 粒子/震动/冒字只在 1.5s 窗口内花钱；结束后必须归还 `Renderer.stale`（现在「静止不重绘」的根基不能破）
- `prefers-reduced-motion` / 减少动效：**关震动、关粒子、关滑入，保留白闪一帧与冒字**（信息不能丢）
- 音效默认音量仍 0.25；静音时不创建 `AudioContext`（现状已守）
- 三个独立开关：`Audio.OPTS.capture2`、`Renderer.OPTS.captureFx`、`UI.OPTS.captureBanner`

### 3.6 验收

1. 盲听：胜/败各 10 次随机播放，≥8 次能分辨
2. 手感：破城 400ms 内同时出现「震 + 白闪 + 碎块」；震动幅度 ≤ 4px、无累积（连破不叠震）
3. 信息：不看纪事也能从画面读出「得了多少战功 / 是否晋升」
4. 性能：特效窗口内 `rasterProbe()` ≤ 12ms；窗口结束后帧率回到静止基线
5. 无障碍：`prefers-reduced-motion` 下无震动/粒子/滑入，冒字与颜色变化保留
6. 可回退：三个开关独立关闭后行为回到本批次之前

## 4. 建议批次（按性价比）

| 批次 | 内容 | 收益 | 风险 | 前置 |
|---|---|---|---|---|
| **A1** | 城池 ①材质分离 + ②坡屋顶 + ③冷暖收光 | ★★★★★ 一眼变「建筑」 | 低（纯取色/画法） | — |
| **A2** | 城池烘焙缓存 + ⑤等级阶梯 + ⑥城内填充 | ★★★★ 近景细节 + 帧率反而变好 | 中（缓存失效时机） | A1 |
| **B1** | 底图 ②等高线 + ③聚簇山树 | ★★★★ 一眼变「老地图」 | 低（纯预渲染） | — |
| **B2** | 底图 ①软权重混合（消台阶）+ ④水系渐变 + ⑤纸层次 | ★★★★ 去掉最大的症结 | 中（全图配色变化，需人工过图） | B1 |
| **C1** | 破城：冲击音 + 震动 + 白闪 + 碎块 + 翻旗 | ★★★★★ 手感质变 | 中（fx 生命周期 / 眩晕） | — |
| **C2** | 破城：总线 + 混响 + 连破升调 + 冒字/滚动 + 晋升仪式 | ★★★★ 正反馈闭环 | 中（音频工程化） | C1 |

推荐顺序：**A1 → C1 → B1 → A2 → C2 → B2**（先各拿一个「一眼可见」的胜利，再做工程化的部分）。

## 5. 明确不做（避免越做越重）

- 不做贴图素材（零外链是本项目硬约束：字体缺失都不该让画面塌）
- 不做真实 3D / 光照贴图 / 阴影贴图
- 不做昼夜循环与天气系统（会让底图预渲染重做成动态管线）
- 不做逐帧单位动画（军队仍是符号，动效只给「事件瞬间」）
- 不做粒子的物理碰撞与落地停留（碎块落地即淡出）

## 6. 统一验收口径

| 项 | 口径 |
|---|---|
| 帧率 | `rasterProbe()`：远景 ≤ 2ms、近景 ≤ 5ms、特效窗口 ≤ 12ms |
| 观感 | 三档缩放截图人工过：能读等级、能读地形、能读关系 |
| 回归 | `verify.js` 全绿；`shots.js` 8 机位差异只允许「新增细节」，不允许既有元素位移 |
| 无障碍 | 减少动效关震动/粒子/滑入；音效可关；静音不建 AudioContext |
| 可回退 | 每批一个开关（`OPTS.cityArt` / `OPTS.terrain2` / `OPTS.captureFx`），关掉即回到本批之前 |
