# P3 外交系统 · 设计稿

> 状态：**D1–D4 已实现**（`js/systems/diplo.js` + `js/data/diplo.js`，验收在 `tools/verify.js`「外交」「外交长跑」两段）
>
> 实现时的落地取舍（与设计稿的差异）：
> - 求援 / 借粮不再点地图选城，固定落到玩家首城（`player.homeCityId`），少一层交互
> - 上表「同一提案 3 回合不可重复」直接复用「每目标国 3 回合冷却」，不另设提案锁
> - 背刺写入口是命令层的 `guardAttack()`（`DISPATCH` / `BATCH_DISPATCH` 共用），UI 负责二次确认
> - 开局关系：全员中立，唯董卓与各国 −45（讨董背景）
> - 停战 / 结盟期内在途的攻军抵达时自动班师，不触发战斗（`Army.arrive`）
>
> 已确认的四项决策：
> 1. 外交只花**钱**，但**每个目标国 3 回合冷却**，防「有钱就无限派使者」
> 2. 保持官阶分层（州牧上表、三公直接），但**任何官阶都能私自背刺**，代价是全球关系惩罚
> 3. AI **真结盟 + 真援军**（需要新的 `mission: 'aid'`）
> 4. **做「投靠」**，放在 D2，补完容错链

## 0. 现状与缺口

现在 22 个势力处于**永久全面战争**：任何势力可以无条件攻击任何相邻势力。

- `js/systems/ai.js:121` 与 `:184` 选目标时只判断 `nb.owner === f.id`（跳过自己），
  没有任何关系或状态检查
- 没有关系值、停战、结盟、宣战的概念
- `G.factions[fid]` 只有 `{ id, name, color, rulerId, aggression, kind, treasury, tech, bonus }`

后果：世界只能一路兼并到死，玩家既无法拉盟友也无力自保，且中后期节奏过快
（实测主动玩家 50 回合滚到 48 城）。外交同时是**玩法补全**和**节奏刹车**。

## 1. 目标与非目标

### 目标
1. 势力之间有关系与状态，**开战需要理由**，和平是可达成的状态
2. 玩家作为城主能用**个人手段**在夹缝里求生（贿赂、密约、求援、投靠）
3. 官阶越高，越能把自己的意志变成**国家行为**（上表 → 代君行令）
4. AI 会结盟、会求和、会背刺，不是一堆只会往前冲的僵尸
5. 让世界演化变慢：从"全员死战"变成"打—停—拉帮结派—再打"

### 非目标（本轮不做）
- 不做复杂的联姻/质子/朝贡体系
- 不做外交胜利（胜负仍只看一统）
- 不做全屏外交地图或关系网可视化（先用列表）
- 不做"联合国大会"式多边谈判

## 2. 核心模型

### 2.1 双边关系（一个数 + 一个状态）

```js
G.diplo = {
  "caocao|yuanshao": {
    rel: -35,          // -100..100，0 = 互不关心
    status: 'war',     // 'war' | 'neutral' | 'truce' | 'ally'
    until: 0,          // truce 到期回合
    since: 12,         // 当前状态起始回合
    treaty: null,      // 盟约内容（结盟时写入，见 §4.4）
  }
}
```

key 用 `[min(fid), max(fid)].sort().join('|')` 规范化，保证 A→B 与 B→A 是同一份数据。
未出现的 pair 视为 `{ rel: 0, status: 'neutral' }`（稀疏存储，22 势力最多 231 对）。

### 2.2 状态机

```
                   宣战 / 背刺
        ┌──────────────────────────────┐
        ▼                              │
   ┌─────────┐   求和(接受)   ┌────────┐│
   │  war    │ ─────────────▶ │ truce  ││
   └─────────┘                └────────┘│
        ▲                          │    │
        │ 到期                      │期满 │  宣战
        │                          ▼    │
        │                     ┌──────────┴─┐
        └─────────────────────│  neutral   │
                宣战           └────────────┘
                                   │  ▲
                            结盟   │  │ 解盟/背刺
                                   ▼  │
                                ┌───────┐
                                │ ally  │
                                └───────┘
```

规则：

| 转移 | 条件 | 后果 |
|---|---|---|
| neutral → war | 主动宣战 | rel −30；对**所有其他国家** rel −4（好战名声） |
| war → truce | 求和被接受 | `until = turn + 12`；rel +10；双方停攻 |
| truce → neutral | `turn > until` | rel 保持 |
| neutral → ally | rel ≥ 40 且 有共同敌人 且 未背刺过 | 写入 `treaty` |
| ally → neutral | 任一方解盟 | rel −20 |
| 任意 → war（背刺） | 无视当前状态直接打 | rel −40；对**所有国家** rel −12；被背刺方对施害者永久记仇（`grudge: true`） |

**没有宣战就攻击 = 背刺**，代价极高。这条是外交能起作用的关键：
想让 AI 别乱打，就得让"乱打"有成本。

### 2.3 关系值漂移（每月）

```
rel += 漂移
       - 3      若 status = war        （越打越恨）
       + 2      若 status = truce
       + 4      若 status = ally
       + 6      若存在共同敌人（同处战争状态的第三方）
       - 5 × 共同边界数                （边境摩擦，最多计 3 条）
       - 2 至 4  若为宿敌（剧本 rivals 表，每月随机）  —— 乱世结不完的旧怨
       + 实力差距修正：强邻 −3，弱邻 +2（弱者更愿意示好）
       → clamp(-100, 100)
```

共同边界数用 `State.neighbors` 算：两势力任意一对相邻城池算一条边界。
这个值缓存在 `G.diplo[k].border` 里，每 6 回合重算一次（70 城规模下没必要每月算）。

## 3. 三层权限

玩家的身份决定他能做什么，这是本系统的骨架。

### 第 0 层｜个人外交（开局即用，不看官阶）

花的是**自己直辖城的钱**，动的是**他国对你个人的观感**，可能**惹自己君主不快**。

**冷却**：同一目标国 3 回合内只能做一次外交动作（`G.player.diploCooldown[fid]`）。
这是唯一的外交成本闸门 —— 不引入新资源，但杜绝「有钱就刷满关系」。

| 行动 | 花费 | 效果 | 风险 |
|---|---|---|---|
| 遣使修好 | 300 钱 | 目标势力对我国 rel +6（你在帮国家说话） | 好感 −2（擅自结交） |
| 私通密约 | 800 钱 | 目标势力 **12 个月内不主动攻你的直辖城** | 被发现（30%）→ 好感 −15，rel −10 |
| 求援 | 1000 钱 + rel ≥ 20 | 目标势力派一支军队到你指定城池（并入守军） | 好感 −5；对方索要"人情"，3 回合内有 40% 概率反过来要你出兵 |
| 借粮 | 600 钱 + rel ≥ 10 | 目标势力给你指定城 +粮（按对方城池规模） | 好感 −3 |
| 行贿上级 | 500 钱 | 本国君主好感 +12 | 被同僚检举（15%）→ 好感 −6，声望 −5 |
| 投靠 | — | 带着直辖城并入目标势力，成为其城主，官阶重置为县长 | 不可撤销；原势力即刻敌对 |

**「私通密约」是城主的生存核心**：你是小人物，打不起仗，只能花钱买太平。
但它只保护**你的直辖城**，不保护本国其他城 —— 这符合"你只管自己的城"的人设。

### 第 1 层｜上表言事（官阶 ≥ 4 州牧）

你已经能进朝堂说话了，但**决定权仍不在你手里**。

| 行动 | 花费 | 效果 |
|---|---|---|
| 上表宣战 | 好感 −10 + 800 钱 | 向君主提议对某国宣战 |
| 上表求和 | 好感 −6 + 600 钱 | 提议与交战国停战 |
| 上表结盟 | 好感 −12 + 1000 钱 | 提议与某国结盟 |
| 上表离间 | 1500 钱 | 在 A、B 两国之间制造摩擦（两国 rel −20） |

君主是否采纳由 AI 判定（见 §5.3）：

```
采纳概率 = clamp(0.15 + 好感/150 + 战略契合度, 0.05, 0.95)
战略契合度：宣战看能否打赢（+0.25 若目标弱），求和看是否在输（+0.3 若丢城），
            结盟看是否有共同敌人（+0.3）
```

被拒：好感 −4，`missionCooldown` 机制不占用，但同一提案 3 回合内不可重复。

### 第 2 层｜代君行令（官阶 ≥ 6 三公）

直接以国家名义行事，不再上表。可执行第 1 层的全部行动，**无需好感与概率判定**，
但每次行动好感 −5（权臣干政的代价），且会累积 `player.usurp` 计数；
`usurp ≥ 5` 触发君主猜忌事件链（好感骤降 / 削权）。

### 第 3 层｜自立之后（路线 = independent）

自己就是君主，直接行使势力外交，无好感成本。
副作用：所有旧盟友关系转为中立，原势力立刻敌对（已有逻辑）。

## 4. 势力外交行动（AI 与玩家共用）

### 4.1 宣战 `DECLARE_WAR`
- 前置：非 ally、非 truce（truce 期宣战 = 背刺）
- 花费：500 钱（国库）
- 效果：状态转 war，rel −30，全球 rel −4

### 4.2 求和 `SUE_FOR_PEACE`
- 前置：status = war
- 花费：钱（按对方实力与战况浮动，`losses × 80`）+ 可能割城
- 对方是否接受：`rel > -70` 或 对方也在挨打（多线作战）
- 效果：状态转 truce（12 回合），rel +10

### 4.3 结盟 `FORM_ALLIANCE`
- 前置：status ∈ {neutral, truce}，rel ≥ 40，无 `grudge`
- 花费：1000 钱
- 盟约内容 `treaty`：
  - 互不攻击
  - 一方被攻时，另一方 50% 概率出兵来援（按 `aggression` 与 rel 调整）
  - 不互相抢城（打下的城归自己，但不可索取对方原有城）
- 联盟上限：每势力最多 2 个盟友

### 4.4 解除盟约 `BREAK_ALLIANCE`
- 无花费，rel −20，全世界 rel −6（背信）
- 3 回合冷却后才能宣战原盟友

### 4.5 请盟出兵 `CALL_TO_ARMS`
- 前置：status = ally，目标势力正被攻打
- 花费：500 钱
- 效果：盟友派军援助（`Army` + mission `aid`，抵达后并入被攻方守军）
- **实现注意**：`Army.arrive` 现在只在 `target.owner === a.factionId` 时合兵，
  友军援助会被当成攻击。需要新增 `mission: 'aid'` 分支，抵达时直接并入守军。

## 5. AI 外交

### 5.1 评估频率与开销

每势力**每 3 回合**评估一次（错开相位：`fid 哈希 % 3 === turn % 3`），
避免 22 势力 × 231 pair 每月全量计算。

### 5.2 决策顺序

```
每月（轮到评估时）：
0. 剧本野望：若当前回合落在 ambitions 的时间窗内、目标仍在且中立
   → 先把两国 rel 压到 −45 以下
   → 必战条目（sure）直接宣战；非必战要求自身实力 > 对方 × 1.05，概率 0.30 + aggression × 0.35
   （必战条目不受 1/3 相位错开限制，否则窗口一过就打不起来）
1. 战况检查：若正在多线作战且丢城 → 找最强的敌国求和
   议和只考虑开打已满 6 个月（MIN_WAR_MONTHS）的战线，否则天下只剩嘴上开战
2. 威胁排序：threat(x) = 邻国实力 × (关系为 war ? 2 : 1) × 接壤系数
3. 若 threat_max > 自身实力 × 1.5
   → 在威胁较小的国家里找 rel ≥ 25 的，提议结盟（上限 2）
4. 若自身实力 > 邻国 × 1.8 且 rel < −40 且不在 truce
   → 宣战（概率 = aggression × 0.5）
5. 若 rel > 60 且无共同敌人 → 尝试解盟再战（权谋，5% 概率）
```

### 5.0 大势：剧本骨架（乱世感从哪来）

光靠"实力 1.8 倍 + rel < −40"的随机宣战，前 20 回合地图基本不动 —— 那是和平年代。
剧本用两张表把历史进程钉住：

| 表 | 文件 | 作用 |
| --- | --- | --- |
| `ambitions` | `js/data/scenarios/taodong190/ambitions.js` | 每势力若干条 `[目标, 起回合, 止回合, 缘由, 必战?]`，窗口内只想着打这一家 |
| `rivals` | 同上 | 宿敌对，关系每月自然 −2~−4，剧本没写到的仇也会打起来 |

历史骨架（讨董 190 开局）：

- 第 2–3 回合：董卓 vs 张杨 / 袁术 / 韩馥 / 袁绍 / 公孙瓒 / 曹操 / 孙坚（**关东会盟讨董**）
- 袁绍：韩馥（冀州）→ 公孙瓒（界桥）→ 曹操
- 曹操：陶谦（徐州）→ 袁术（淮南）；陶谦反向还手
- 孙坚 / 刘表互攻，袁术取荆襄；公孙瓒 vs 刘虞；黑山军 vs 韩馥 / 袁绍
- 马腾 vs 韩遂；刘焉 vs 刘表

**天下大事播报**：势力间的宣战 / 停战每月最多播报一条（`【天下】…`，`Diplo._news`）。
不加这条，玩家开着县令视角压根不知道别处在打仗——地图看着就是静止的。

调这几个旋钮就够了：窗口（何时）、目标（打谁）、`sure`（是否必战）、`MIN_WAR_MONTHS`（仗打多久才能议和）。

### 5.3 君主如何评价玩家的上表

```
score = 好感/100                       // 你有多受信任
      + 提案类型权重（宣战看能否赢：目标实力/我方实力 < 0.8 则 +0.25）
      + 君主 aggression 契合度
      − 该提案近期被拒次数 × 0.1
采纳 = RNG < clamp(0.15 + score, 0.05, 0.95)
```

### 5.4 对玩家的特殊处理

不加"AI 优先打玩家"的硬编码，但保留现有的**新手保护**（前 24 回合不攻玩家势力、
前 42 回合不攻玩家直辖城）。外交生效后，保护可以缩短甚至取消 ——
因为玩家已经能用密约和结盟自保。

## 8. 平衡护栏

1. **联盟上限 2**，且不能连锁（A-B 盟、B-C 盟 ≠ A-C 盟）
2. **背刺代价**：全球 rel −12，且被背刺方永久 `grudge`（不再与其结盟）
3. **停战期最短 12 回合**，防止打打停停刷关系
4. **关系值漂移上限**：单月变化不超过 ±10，避免剧烈翻转
5. **AI 不会无限求和**：同一对势力两次求和之间至少 18 回合
6. **对玩家无特殊仇恨**，靠关系和实力说话

D1 单独就能改善节奏问题，建议先做完 D1 再评估。

### 决策带来的两个连带改动

- **背刺是唯一能绕过君主的开战方式**，因此它必须足够疼，否则分层就没意义。
  惩罚组合：全球 rel −12（别国不敢跟你结盟）+ 君主好感 −20 + 声望 −15。
- **援军需要新 mission**：现状 `Army.arrive` 只在 `target.owner === a.factionId` 时合兵，
  友军援助会被判定为攻城。必须新增 `mission: 'aid'` 分支，且 aid 军不能触发 `Combat.resolve`。
