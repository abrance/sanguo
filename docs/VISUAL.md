### 当前已知的视觉弱点（后面方向的动机）

1. 地形**过渡仍是 40px 网格分类**的结果：色床把台阶糊平了，但"森林忽然变平原"的**面积边界**还是方块状。
2. 城池**只有一种形制**：大城小城同样三个雉堞，看不出主次；城墙等级（1–5）完全没体现。
3. 军队只是一枚三角，**看不出兵种、看不出规模**，敌人来攻时冲击感不足。
4. 信息层**字号与间距零散**（10/11/12/13 混用、px 不统一），长期维护会让 UI 越来越"补丁感"。
5. 战报是**连续文本行**，一场攻城 6–10 行，翻查困难。
6. **没有音效**（P5 唯一硬缺口），也没有"回合过场"，每月点击的节奏感靠文字承担。
7. ~~视觉没有任何自动回归~~ —— 已有 `node tools/shots.js` 三机位像素回归；但它只覆盖 3 个机位，
   城池新画法的细节仍靠 [STYLE/TESTING](TESTING.md) 里那套像素扫描口令人工核对。

## 2.0 已实现：城池 3D 立面（斜投影）

> 这一节写的是**已经落地**的做法与旋钮，其余各节仍是方向清单。

### 旋钮（一处改，整张图跟着变）

```js
Renderer.ISO = {
  height:   1.25,   // 立面高度系数（屏幕 px / 城半径）；0 = 退回原平面画法
  skew:     0.24,   // 东面宽度 / 高度（斜投影角度，越大越像等距）
  front:    0.62,   // 南面压暗（正对观者的背光面，最暗）
  side:     0.75,   // 东面压暗（侧向背光面，稍亮）
  flagLift: 0.9,    // 旗杆随城抬升（1 = 插城头，0 = 仍插地面）
}
```

高度不是常数：`cityHeight(r, tier, wall, wallMax)` = 档次（都城 1.05 / 郡城 0.82 / 县城 0.60）
× 城墙等级补正（最高 +18%）。**光源固定在西北**，与 `map.js` 山体侧影同向 —— 改一边必须改另一边。

### 绘制顺序（顺序就是正确性）

```
按世界 y 升序（画家算法，北边的城先画）
└ 每座城：
   1. 地影         ellipse，往光的反方向（东南）拖 z*0.5，墙越高影越长
   2. 直辖光晕     底平面外扩椭圆（远景色点另走圆形光晕）
   3. 选中/悬停环   底平面椭圆，夹在地影与城体之间 —— 上弧被楼挡、下弧不被地影盖
   4. 南面         平行四边形 shade(color, ISO.front)
   5. 东面         平行四边形 shade(color, ISO.side)，宽 z*ISO.skew
   6. 城门 + 接地暗线
   7. 顶面         translate(dx, -z) 后走原有整套画法
   8. 南墙垛口      必须在顶面之后，否则被屋顶前沿压住
   9. 营地 / 旗 / 治所星 / 关系弧 / 铭牌 / 兵力
```

立面**必须是平行四边形**（底平面边 ↔ 顶平面边连线）。用 `fillRect` 会整块落在顶面之下、
被随后画出的顶面完全盖住 —— 东墙等于不存在，轮廓右下角缺一块。

### LOD

| zoom | 画什么 |
|---|---|
| < 0.5 | 色点 + 东南向接地影（远景不需要面，也省性能） |
| 0.5 – 0.8 | 立面 + 顶面 + 城门 + 治所星；**不画**垛口/角楼/内城（1.5–2px 的垛口实测 1651px 全是糊，收益为负） |
| ≥ 0.8 | 全量：垛口 / 角楼 / 内城 / 破损裂缝 / 铭牌 / 兵力 |

### 命中检测（跟立面走）

`pick()` 分两条路径：远景按圆；近景按**立面包围盒**
（`x ∈ [城心 − w/2 − 8, 城心 + w/2 + z·skew + 8]`，`y ∈ [屋顶上沿, 城基下沿]`）。
旧版统一用 `r + 8` 的圆判定，城抬到 40px 高以后**点楼身选不中**。
多城包围盒重叠时取离底平面中心最近者。

### 验收方法（美术也要能"过"）

```bash
node tools/shots.js          # 三机位像素差（改完必须 0px 或说明为什么不是）
node tools/verify.js         # 分层守护：view 不写状态、不出现裸色值
```

面与面的颜色可以数出来：`?shot=1&zoom=2.2&cx=1080&cy=730` 取洛阳（董卓军 `#8b2f2f`），
竖直扫描依次应读到 `(139,47,47)` 顶面 → `(95,34,34)` 院内 → `(86,29,29)` 南墙 →
`(16,10,8)` 城门 → 灰褐地影，即 1.0 / 0.68 / **0.62** / 城门 / 影，与 `ISO.front` 对得上。

## 5. 音效（P5 唯一硬缺口）

原则：**零素材、纯 WebAudio 合成**，不引入音频文件；默认音量低，提供静音开关并记忆；首次用户交互后解锁（浏览器 autoplay 政策）。

| # | 方向 | 做法 |
|---|---|---|
| 5.1 | 基础音色 | 3 个原语：`blip(freq, dur, type)`、`noise(dur, filter)`、`thud(freq)` |
| 5.2 | 事件映射 | 按钮 click（短 blip）、结束回合（低音 thud + 轻噪声）、攻城（噪声爆 + 低频）、城破（下行三音）、外交成/败（上行/下行二音）、上命到期（双短促提示） |
| 5.3 | 节流 | 同一帧同类音只播一次；战报刷屏时降级为无声；切后台静默 |
| 5.4 | 开关 | 底部栏一个 ♪ 图标切换（`localStorage` 记忆），默认开但音量 0.25 |

## 8. 明确不做（边界，避免越做越重）

- **不引入任何图片/字体/动画库**：保持零依赖、零构建（`index.html` 只挂自己的 js/css）
- **不做 3D / 斜视角 / WebGL**：canvas 2D 手绘风是这套美术的立身之本
- **不做地形网格运行时重生成**：底图一次性预渲染，改美术不动规则
- **不做武将头像生成器**：收益低、成本高、易成"AI 味"素材
- **不做多主题皮肤商店**：一套土黄绢本主题做到位，比三套半成品强
- **不为美术改规则层**：所有方向只允许动 `js/view/**` + `style.css` + `index.html`；需要新状态（如"被攻过的城"）必须先过 `Store.dispatch` 与 `verify.js`

## 10. 验收口径（美术这种东西也要能"过"）

1. **静态可读**：任取一张全图截图，不点任何面板也能说出「谁占哪片、哪儿是山、哪儿是水、哪座城最大」
2. **动态有反馈**：一次攻城 → 有冲击、有战报卡、有声音（可静音）；一次结束回合 → 有过场、有月份提示
3. **不劣化**：`Renderer.draw` < 8ms、`prerender` < 150ms、`verify.js` 全绿、控制台无错
4. **可回退**：每个方向独立开关（CSS class 或 `Renderer.opts`），方便 A/B 与快速撤销
5. **有基线**：第四档落地后，视觉改动必须过截图基线，否则不算完成

## 11. P7 手感批次：规格与验收（本次新增，2026-10）

> 这一节把 §2.1 / §2.2 / §3.13 / §4.1 / §5 五个方向**落到可实现规格**，是"挖深"而非新方向。
> 目标一句话：**不动玩法，先让现有玩法看起来是个成品。**

### 11.1 城池形制分档（对应 §2 城池方向，现状：只有 3 档尺寸）

现存问题：`cityTier` 只影响底平面尺寸 / 立面高度 / 垛口条数（2→5 / 1→4 / 0→3），城墙等级只给 +18% 高度。结果：县城与郡城差别很小，帝都（洛阳/长安）与普通都城一模一样。

**规格**（只改 `renderer.js` 的 `drawCity`，`cityTier` 契约不动）：

| 元素 | tier 0 县城 | tier 1 郡城 | tier 2 都城 | 帝都附加（`c.id ∈ Renderer._imperial`） |
|---|---|---|---|---|
| 底平面 | 1.00 | 1.06 | 1.12 | 同 tier 2 |
| 立面高度系数 | 0.60 | 0.82 | 1.05 | +8% |
| 垛口条数 | 3 | 4 | 5 | 6 |
| 角楼 | 无 | 2（南角） | 4 | 4 + 阙楼一对（门前左右，高 0.5z 的方柱顶小檐） |
| 内城 | 有 | 有 | 有 + 内城楼 | 内城楼 + 金描边（`--gold`） |
| 城墙等级 | | | | |
| ≤2 | 无护城河 | 无 | 河（椭圆环，浅蓝） | 河更宽 |
| 3-4 | 河 + 单门 | 河 + 单门楼 | 河 + 双门楼 | 双门楼 + 马面 2 处 |
| ≥5 | 双门楼 + 马面 | 双门楼 + 马面 3 | 双门楼 + 马面 4 | + 望楼（顶部小塔） |

- **破损**：`wall < wallMax` 时按缺口比例（`1 - wall/wallMax`）在南墙挖 1-2 段缺口（现有 `gapIdx` 逻辑扩展为"缺口段数 = round(比例×2)+1"），缺口内画焦色短线（`--ink-3`）
- **LOD**：`lod < 2`（远）只画到"垛口条数"这一行，不画角楼/门楼/马面（§1.12 已有 LOD 契约，这里只是加规则）
- **性能预算**：每城绘制耗时 ≤ 0.06ms（当前 70 城 ≈ 3ms，留 40% 余量）；`detail=false` 时新增元素全跳过
- **开关**：`Renderer.OPTS.cityForms = true`，出问题一键回到旧形制

### 11.2 军队形制（对应 §2 军队方向）

现状：一枚三角，看不出兵种与规模。

| 维度 | 规则 |
|---|---|
| 兵种主导 | 按兵力占比最大的兵种：步=方阵（3×2 小方块）/ 骑=马形（梯形 + 前须）/ 弓=雁行（3 个斜置小三角）/ 水=舟形（长六边形）/ 器=辎重（方 + 轮点） |
| 规模 | `total < 500` 1 个队形 · `<2000` 2 个 · `<5000` 3 个 · ≥5000 4 个（横向排开，间距 0.9 个单元） |
| 势力色 | 队形填势力色（同城池旗），描边 `--ink` |
| 状态 | 移动中：队形之间画 1px 虚线拖尾；攻城中：加一个脉冲圆环（周期 1.2s，减少动效时静止） |
| 选中 | 现有三角高亮保留，额外在队形下方画短横线（命中区域基线） |
| 命中检测 | 扩张到队形包围盒（不要只点中心，现有 12px 半径太苛刻） |

### 11.3 回合过场（对应 §4 动效方向）

现状：点「结束回合」后底栏一行 toast，**没有任何过渡感**。

时间轴（总 360ms，可跳过）：

```
  0ms   遮罩淡入（全屏 `--bg-veil`，alpha 0 → 0.55）   + 月份牌从下方滑入
 60ms   月份牌定格：大字「初平元年 · 三月」 + 下方小字「春 · 青州」
160ms   季节色调 overlay 开始（春青/夏饱/秋黄/冬灰，alpha 0 → 0.10）
320ms   遮罩淡出，月份牌上移消失，地图恢复
360ms   完成，可以继续操作
```

- **跳过**：任意点击 / 空格 → 立即跳到 360ms（不吞输入）
- **连点保护**：过场中再次请求结束回合 → 排队，不叠加（`UI.busy` 复用现有 busy 锁）
- **减少动效**：`prefers-reduced-motion` → 直接 320→360 两帧，只留 toast
- **边界**：战斗弹窗未关闭时不播过场（先看战报）
- **数据来源**：`G.meta.year/month` 现有字段；季节名走 `SEASON` 表，不新造

### 11.4 战报卡片（对应 §3.13）

现状：连续文本行，6-10 行翻查困难。

```
┌ 第 3 / 6 轮 · 城门破 ────────  伤亡 420 / 130 ┐
│  攻方：步1200·骑300   守方：步800·弓200      │  ← 每张卡固定 2 行信息
│  「云梯抵城，箭如雨下。」                      │  ← 一句文学化描述（现有战报文案复用）
└──────────────────────────────────────────────┘
```

- 卡片列表默认**全部展开**（6 张才 60 行，折叠反而要多点一次）；提供「只看关键轮」开关 → 只显示"城门破 / 伤亡 > 15% / 最后一轮"
- 战法轮：卡片左边框 `--warn`，标题追加「· 火计」
- 键盘：`↑↓` 切换卡片，`Enter` 展开/折叠
- 底部固定一行：[战法按钮（未到可用时机则整行不显示）] [继续]
- 数据结构：`Combat.round` 返回 `{ roundNo, atkLoss, defLoss, line, tag }`（`tag ∈ normal|gate|tactic|final`），视图层只消费这个

### 11.5 音效（对应 §5，P5 唯一硬缺口）

**零素材**：全部 WebAudio 合成，新增 `js/view/audio.js`（≈120 行）。

| 事件 | 合成方式 | 时长 | 音量 |
|---|---|---|---|
| 翻月 | 木质双击：方波 880Hz → 440Hz，指数衰减 | 90ms | 0.12 |
| 开工 | 石块敲击：噪声 + 低频滤波（200Hz） | 120ms | 0.10 |
| 出征 | 号角：锯齿波 220→330Hz 上滑 + 轻混响 | 260ms | 0.10 |
| 破城 | 低频撞击 + 噪声爆（低通 400Hz） | 400ms | 0.18 |
| 警报（城被围/忠诚预警） | 三角波两短音 660Hz | 200ms | 0.14 |

- **首次交互解锁**：`AudioContext` 必须在用户手势后 resume（现有 `ui.js` 已有全局 click 绑定，挂那里）
- **静音开关**：顶栏加一枚喇叭图标，状态存 `localStorage.sanguo.muted`（不进存档，跨局保留）
- **减少动效不关闭音效**（两码事）
- **性能**：所有音共用 1 个 `AudioContext` + 每次现合成（不用 `<audio>` 元素，避免加载态）
