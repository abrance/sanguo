# 三国 · 讨董 190

一个纯前端的单人回合制三国策略游戏。你是乱世中的一城之主 —— 效忠一方、营建城池、积攒战功、步步高升，或者自立门户。

原型取材自《丝路英雄》的「经营 + 武将 + 大地图」三件套，换成三国题材，以多剧本平行时间线为长期方向。

## 跑起来

零依赖、零构建。任意静态服务器即可（直接用 `file://` 打开会让 localStorage 不可用，不推荐）：

```bash
cd sanguo
python3 -m http.server 8080
# 浏览器打开 http://localhost:8080
```

或者用 VS Code 的 Live Server 插件。

## 现在能玩什么

### 地图与回合
- 选择势力（21 家）与起始城池，自定义城主名
- 70 郡 Canvas 大地图：拖拽平移、滚轮缩放、点击城池
- 回合推进（一回合 = 一个月），四季影响粮产、税入、征兵、建设

### 内政
- **4 种资源**：粮、钱、建材、铁料，外加势力级科研点
- **16 种建筑**，各 2-6 级：农田、市集、城墙、伐木场、采石场、冶铁坊、马场、兵营、校场、府衙、学宫、粮仓、医馆、烽燧、船坞、关市
- 建造有工期与工程位（府衙 3 级起可并行两项），可撤项退半料
- **科技树 40 项**（农 / 工 / 商 / 军 各 10 层），学宫产点（每级 6 点/月），可排队 3 项，效果直接作用于经济与战斗
- **士族系统**：每城 2-3 家大族，满意度与影响力影响钱粮产出、兵额、叛乱风险
- **太守委任**：给直辖城指定「重农 / 备战 / 商贸 / 筑城 / 均衡」，每月自动营造与征兵

### 仕途（P2）
- **官阶台**：侧栏按钮打开全屏面板，看 7 阶阶梯、晋升门槛、解锁权限、当前上命与权柄
- **三路线**：忠臣（受赏 / 门槛低 / 上限小）、权臣（可征调同僚兵力、可截留税赋 / 招君主猜忌）、自立（全权自主 / 招原势力宣战）
- **举兵自立**：刺史以上 + 2 座直辖城 + 声望 150 → 脱离原势力，自建「<名字>军」，接管直辖城与城内武将，继承科技树
- **上命**：每 4 回合一条上级任务（催征上贡 / 募兵上缴 / 奉命征讨），完成得战功与好感，逾期与抗命要付代价
- **上级好感**：影响直辖城上限；高了好感有赏赐，低了好感会被削权

### 军事
- 兵种：步 / 骑 / 弓 / 水 / 器，各兵种有独立兵额（骑兵需马场、水军需船坞）
- **兵额公式全透明**：面板里直接列出 户籍 × 农田 × 治安 × 兵营 × 校场 × 士族 × 科技 的逐项推导
- **一键补兵**：按兵额一次补足，不用逐个兵种点
- **批量操兵**：军务页勾选多城，「补齐所选」一次补完，「所选调兵」选好比例后点地图目标城，多路同时进军（自动避开已在外的武将）
- **持续调兵（补给线）**：城池 → 施政页设「每月送走本城 X%」「补至目标兵额 X%」+ 点地图选目标，之后每月自动补兵到目标城（补满即停，目标掉兵自动恢复）；面板会列出三个限制并标出哪个在生效，城池副标题显示「就绪 / 送 / 满 / 兵少」。抽得狠会一次抽空本城，配合「备战」方针才能形成不断的流水
- 出兵：选抽兵比例（30/50/70/90%），点地图目标城，悬停显示胜算预估
- 多轮攻城战斗 + 中文战报（地形、克制、武将特技、逐轮伤亡、城门破、医馆收治伤兵）
- 战功分封 → 官阶晋升（县长 → 丞相，7 阶）→ 直辖城上限提高

### 其他
- 21 个 AI 势力自行征税、营造、征兵、研究、集结、多路出兵，大势滚雪球
- 失城流亡：直辖城全失不会立刻出局，被势力重新任命到最弱一城
- 自动存档 / 存档 / 读档（localStorage，旧存档自动迁移）
- 胜负：本方势力统一全图即胜；本方势力一城不剩即败

## 操作

| 操作 | 说明 |
|---|---|
| 拖拽 / 滚轮 | 平移 / 缩放地图 |
| 点击城池 | 打开城池面板（概览 / 营造 / 士族 / 施政） |
| 侧栏标签 | 城池 / 军务 / 科技 / 纪事 |
| 募兵按钮 | 从该城城库扣钱扣丁口补兵；不可募时按钮上直接写明原因（如「丁口不足」） |
| 一键补兵 | 按当前兵额一次补足 |
| 军务 → 批量操兵 | 勾选多座直辖城，批量补兵或批量调兵到同一目标 |
| 城池 → 施政 → 持续调兵 | 设本城每月自动送兵到某城（点地图选目标） |
| 出兵 N% | 进入选目标模式，点地图上目标城进军；Esc 取消 |
| 结束回合 | 推进一个月 |

## 结构

```
index.html          入口，按顺序加载所有脚本
style.css           侧栏、标签页与起始界面样式
js/core/            种子随机、工具、事件总线
js/data/            兵种、官阶与路线、建筑、科技、方针、上命模板、城池、武将、势力、剧本（纯数据）
js/state/           状态构造、命令层（dispatch → reducer）、存档
js/systems/         经济、征兵、建造、科技、士族、太守、上级好感、上命、战斗、行军、官阶、AI、回合流水线
js/view/            地图生成、Canvas 渲染、侧栏 UI
js/main.js          启动与渲染循环
```

改数值只动 `js/data/`；改规则动 `js/systems/`；状态变更必须走 `Store.dispatch(command)`。

## 两条容易踩的规则

- **兵额看户籍，不看现有人口**。征兵消耗的是「丁口」（现有人口），只影响钱粮产出，每月向户籍回升；户籍只由城池底子、府衙、农政科技决定。所以不会越征兵上限越低。
- **城墙很硬**。每级 +22% 守方战力。攻 2 倍兵力打 4 级墙也只有 83% 胜率。守不住就先堆墙。

## 自检

规则层不依赖 DOM，可以脱离浏览器验证：

```bash
node tools/verify.js          # 38 条断言：不变量/命令校验/长跑/战斗曲线/科技链/补给线/存档
node tools/verify.js -v       # 附明细
node tools/sim.js --bot --months 200    # 推演一个主动玩家 200 回合
node tools/sim.js --months 120          # 被动玩家会怎样
```

`tools/harness.js` 直接解析 `index.html` 的 script 列表来装载源码，所以新增文件只要加进 index.html，测试自动覆盖。
