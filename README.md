# 三国 · 讨董 190

一个纯前端的单人回合制三国策略游戏。你是乱世中的一城之主 —— 效忠一方、营建城池、积攒战功、步步高升，或者自立门户。

**两个剧本**：讨董卓（初平元年 190）· 官渡之战（建安五年 200）。起始界面顶部切换，存档按剧本分开。

原型取材自《丝路英雄》的「经营 + 武将 + 大地图」三件套，换成三国题材，以多剧本平行时间线为长期方向。

## 跑起来

零依赖、零构建。任意静态服务器即可（直接用 `file://` 打开会让 localStorage 不可用，不推荐）：

```bash
cd sanguo
make server
# 浏览器打开 http://localhost:10300（Ctrl-C 停止，再 make server 重开）
```

`make server` 走 `tools/serve.py`，带 `Cache-Control: no-store` —— 改完代码刷新就是新代码，
不会出现"明明改了、页面还是旧逻辑"（`python3 -m http.server` 会踩这个坑）。

或者用 VS Code 的 Live Server 插件。

## 现在能玩什么

### 地图与回合
- 选择势力（21 家）与起始城池，自定义城主名
- **开局天赋（6 选 1）**：商人（钱 +25%、外交 -25%）/ 骑兵（行军 +30%、骑兵兵额 +40%）/ 农夫（粮 +25%、仓廪 +30%）/ 将才（战力 +12%、出征士气 +10）/ 工匠（工期 -25%、建材铁料 +20%）/ 纵横家（外交 -40%、关系回暖更快），只作用于你的直辖城与军队
- 70 郡 Canvas 大地图：拖拽平移、滚轮缩放、点击城池。地形为手绘风（平滑色床 + 山体侧光 + 峰形/树丛/沙丘符号 + 河川四叠与支流 + 州界虚线与州名朱印），城池画成城墙雉堞城门并挂势力旗，另有势力色领地晕染、治所星标、城名铭牌、右下罗盘
- 回合推进（一回合 = 一个月），四季影响粮产、税入、征兵、建设

### 内政
- **4 种资源**：粮、钱、建材、铁料，外加势力级科研点
- **16 种建筑**，各 2-6 级：农田、市集、城墙、伐木场、采石场、冶铁坊、马场、兵营、校场、府衙、学宫、粮仓、医馆、烽燧、船坞、关市
- 建造有工期与工程位（府衙 3 级起可并行两项），可撤项退半料
- **科技树 40 项**（农 / 工 / 商 / 军 各 10 层），学宫产点（每级 6 点/月），可排队 3 项，效果直接作用于经济与战斗
- **士族系统**：每城 2-3 家大族，满意度与影响力影响钱粮产出、兵额、叛乱风险
- **人情账（人物页）**：每名武将带忠诚 / 野心 / 私交 / 积怨 / 闲置月数，每月漂移；可赏赐、提拔、责罚、抚慰（各有冷却）
  - 守将忠诚 → 守城战力，主将忠诚 → 建军士气，守将私交 → 城池产出
  - 忠诚 < 30 且野心 > 60 会叛：叛前一月预警，3 月内安抚可挽；叛变会带城投敌，但武将不会消失
- **名望**：破城按城档 +4/+6/+12、自立 −20；名望提高登用成功率，也让 AI 不敢轻易对你宣战
- **在野名士**：拜访 / 送礼 / 三顾三档延揽，成功率逐项透明（私交 / 名望 / 魅力 / 野心 / 智谋）；连败三次后不再涨私交
- **宝物 20 件**：兵器 / 甲胄 / 坐骑 / 典籍 / 印绶，装到武将身上加统武智政魅与守城、行军、名望；破城有概率夺得
- **战法（12 个）**：玩家指挥的攻城战逐轮推进，轮间可放一次战法（火计 / 突击 / 神射 / 铁壁 / 急智 / 无双 / 陷阵 / 水战 / 伏兵 / 断粮 / 夜袭 / 骂阵），消耗士气；专属战法要本将有对应特技
- **太守委任**：给直辖城指定「重农 / 备战 / 商贸 / 筑城 / 均衡」，每月自动营造与征兵

### 仕途（P2）
- **官阶台**：侧栏按钮打开全屏面板，看 7 阶阶梯、晋升门槛、解锁权限、当前上命与权柄
- **三路线**：忠臣（受赏 / 门槛低 / 上限小）、权臣（可征调同僚兵力、可截留税赋 / 招君主猜忌）、自立（全权自主 / 招原势力宣战）
- **举兵自立**：刺史以上 + 2 座直辖城 + 声望 150 → 脱离原势力，自建「<名字>军」，接管直辖城与城内武将，继承科技树
- **上命**：每 4 回合一条上级任务（催征上贡 / 募兵上缴 / 奉命征讨），完成得战功与好感，逾期与抗命要付代价
- **上级好感**：影响直辖城上限；高了好感有赏赐，低了好感会被削权

### 军事
- 兵种：步 / 骑 / 弓 / 水 / 器，各兵种有独立兵额（骑兵需马场、水军需船坞）
- **兵额公式全透明**：面板里直接列出 户籍 × 农田 × 治安 × 兵营 × 校场 × 士族 × 科技 的逐项推导
- **一键补兵**：按兵额一次补足，不用逐个兵种点
- **批量操兵**：军务页勾选多城，「补齐所选」一次补完，「所选调兵」选好比例后点地图目标城，多路同时进军（自动避开已在外的武将）
- **持续调兵（补给线）**：城池 → 施政页设「每月送走本城 X%」「补至目标兵额 X%」+ 点地图选目标，之后每月自动补兵到目标城（补满即停，目标掉兵自动恢复）；面板会列出三个限制并标出哪个在生效，城池副标题显示「就绪 / 送 / 满 / 兵少」。抽得狠会一次抽空本城，配合「备战」方针才能形成不断的流水
- 出兵：选抽兵比例（30/50/70/90%），点地图目标城，悬停显示胜算预估
- 多轮攻城战斗 + 中文战报（地形、克制、武将特技、逐轮伤亡、城门破、医馆收治伤兵）
- 战功分封 → 官阶晋升（县长 → 丞相，7 阶）→ 直辖城上限提高

### 外交（P3）
- **关系与状态**：每个势力对国家有一份 `rel(-100..100)` 与状态（中立 / 交战 / 停战 / 同盟），每月漂移（交战更恨、同盟更亲、接壤越摩擦越差）
- **开战需要理由**：未宣战就出兵 = **背刺** —— 天下关系 −12、对方永久记仇、君主好感 −20、声望 −15（UI 会先二次确认）
- **个人外交（任何官阶）**：遣使 300 / 私通密约 800 / 求援 1000 / 借粮 600 / 行贿上级 500 / 带城投靠；同一目标国 3 回合只能动一次
- **上表言事（州牧+）**：提议宣战 / 求和 / 结盟 / 离间，君主按好感与战略契合度裁定，被拒也要付好感
- **代君行令（三公+ / 自立）**：直接以国家名义宣战、求和、结盟、解盟、请盟出兵；每次 −5 好感，权柄用满 5 次触发猜忌
- **同盟与援军**：每势力最多 2 盟，盟友被攻时可能真派兵（`mission: aid`，抵达并入守军不当攻军）
- **上命新增**：出使（把某国关系提到阈值）、离间（把两国关系压到阈值以下）；征讨类上命只对交战国下，离间类只对州牧以上下（官阶不够时不会派到手）
- **大势剧本**：每家有历史野望（时间窗内既定攻打对象，如袁绍取冀州→界桥→南下），开局即关东会盟讨董；外加宿敌对关系逐月结冰，没写到的仇也打得起来。别国宣战 / 停战每月播报一条「天下」大事
- 地图上城池下方的小弧线即关系：红交战 / 黄停战 / 绿同盟

### 其他
- 21 个 AI 势力自行征税、营造、征兵、研究、集结、多路出兵，大势滚雪球
- 失城流亡：直辖城全失不会立刻出局，被势力重新任命到最弱一城
- 悬停城池速览：守军 / 兵额 / 城墙 / 治安 / 守将 / 该势力与你的态度
- 浮层提示（存档、读档、月份推进）+ 纪事逐条滑入；在建城池城头有微光
- **战报卡片**：一场攻城一张卡（城名 / 城破或不克 / 双方主将 / 伤亡条 / 合数），点开看逐轮战况
- 顶栏粮钱兵 12 月 sparkline + 环比箭头；小地图点击跳转；镜头缓动与拖拽惯性
- 自动存档 / 存档（多槽位，可新建、覆盖、删除、选择读档）/ 导出导入 `.json`（localStorage，旧存档自动迁移）
- 胜负：本方势力统一全图即胜；本方势力一城不剩即败

## 结构

```
index.html          入口，按顺序加载所有脚本
style.css           侧栏、标签页与起始界面样式
js/core/            种子随机、工具、事件总线
js/data/            兵种、官阶与路线、建筑、科技、方针、上命模板、外交、城池、武将、势力、剧本（纯数据）
js/state/           状态构造、命令层（dispatch → reducer）、存档
js/systems/         经济、征兵、建造、科技、士族、太守、上级好感、上命、外交、战斗、行军、官阶、AI、回合流水线
js/view/            地图生成、Canvas 渲染、侧栏 UI
js/main.js          启动与渲染循环
```

改数值只动 `js/data/`；改规则动 `js/systems/`；状态变更必须走 `Store.dispatch(command)`。

## 两条容易踩的规则

- **兵额看户籍，不看现有人口**。征兵消耗的是「丁口」（现有人口），只影响钱粮产出，每月向户籍回升；户籍只由城池底子、府衙、农政科技决定。所以不会越征兵上限越低。
- **城墙很硬**。每级 +22% 守方战力。攻 2 倍兵力打 4 级墙也只有 83% 胜率。守不住就先堆墙。

## 并行开发：一个 worktree 一个会话

两个会话共用一个工作目录会互相切分支、把提交落到对方分支上（已经发生过一次）。仓库零依赖、2MB，
worktree 几乎免费，所以约定：

```
git worktree list                       # 看现在有几棵树、各自在哪个分支
git worktree add ../sanguo-view feat/xxx   # 新开一棵（同一个 .git，独立工作目录 + 独立分支）
git checkout main && git pull           # 主目录始终留在 main，只用来同步
git worktree remove ../sanguo-view      # 合完之后删掉
```

规矩：

- **一个 worktree 只归一个会话**，在里面改完就提交、推送、开 PR，不在树之间切分支。
- **同一个分支不能同时出现在两棵树里**（git 会拒绝，这正是我们要的保护）。
- `tools/shots/` 是被 gitignore 的视觉基线 → **每棵树各自跑一次 `node tools/shots.js --update`**，
  这样别人重拍基线不会把你的回归搞红。
- 未跟踪文件（新写的 `docs/*.md`、临时脚本）不跨树共享，要共用就提交。

## 自检

规则层不依赖 DOM，可以脱离浏览器验证：

```bash
node tools/verify.js          # 295 条断言：不变量/命令校验/长跑/战斗曲线/特技接线/人情账/名望登用/宝物/战法/AI 决策/科技链/补给线/外交/存档
node tools/verify.js -v       # 附明细
node tools/sim.js --bot --months 200    # 推演一个主动玩家 200 回合
node tools/sim.js --months 120          # 被动玩家会怎样
node tools/shots.js                     # 视觉回归：无头截图 vs 基线（需 Chrome + ImageMagick）
```

`tools/harness.js` 直接解析 `index.html` 的 script 列表来装载源码，所以新增文件只要加进 index.html，测试自动覆盖。
